Politique de confidentialité de Louche, non ?

Dernière mise à jour : 21 octobre 2026

Louche, non ? est une application Android gratuite et open source qui aide à repérer les SMS et e-mails frauduleux. Elle est éditée par c4seus.

Aucune donnée collectée

L'application ne collecte, ne stocke et ne transmet aucune donnée personnelle. Elle ne contient ni publicité, ni outil de statistiques, ni traceur, et ne demande aucun compte.

Analyse sur le téléphone

Le texte que vous collez est analysé uniquement sur votre téléphone. Il n'est jamais envoyé à un serveur, ni à l'éditeur, ni à un tiers. Il n'est pas enregistré : il disparaît lorsque vous effacez le champ ou fermez l'application.

Presse-papiers

Le bouton « Coller » lit le presse-papiers uniquement lorsque vous appuyez dessus, pour y récupérer le message à analyser.

Actions vers d'autres applications

Le bouton « Signaler au 33700 » ouvre votre application de messages avec le texte prérempli : rien n'est envoyé tant que vous n'appuyez pas vous-même sur « Envoyer ». Le bouton d'aide de cybermalveillance.gouv.fr ouvre ce site dans votre navigateur. Le lien « Signaler une arnaque » ouvre un formulaire sur GitHub dans votre navigateur, avec le message prérempli : rien n'est publié tant que vous ne validez pas vous-même le formulaire. Ces services ont leurs propres règles de confidentialité.

Permissions

L'application ne demande aucune permission d'accès à vos SMS, contacts, photos ou position.

Code source

Le code est public et vérifiable : github.com/c4seus/Louche-non-.
